# רשימת חסימה לדומיינים זדוניים

<div dir="rtl">

## אודות

רשימת חסימה נלווית, המיועדת לשימוש לצד רשימות חסימה קיימות. הרשימה מרכזת דומיינים שנתפסו והוכחו כפעילות זדונית המזוהה עם ישראל, ובהם קמפייני פישינג, טלמטריה ופשעי סייבר.

הרשימה מתעדכנת באופן שוטף, ולעיתים עוד לפני הודעות רשמיות של מערך הסייבר הלאומי, וזאת על בסיס זיהויים של אנשי סייבר בישראל. הזיהוי משלב תהליכים אוטומטיים עם בדיקה ידנית. בכל הנוגע לטלמטריה, הזיהוי קפדני: כל דומיין נבדק לפני הכללתו ברשימה, והרשימה מתעדכנת בהתאם.

## כתובת הרשימה

</div>

```
https://raw.githubusercontent.com/mad0xStrixhadorami/malicious-domains-blocklist/main/blocklist.txt
```

<div dir="rtl">

ניתן להוסיף את הכתובת ל-AdGuard, ל-Pi-hole או לכל חוסם DNS אחר התומך ברשימות בפורמט hosts.

- Pi-hole: Adlists, הוספת הכתובת, ולאחר מכן עדכון Gravity.
- AdGuard Home: Filters, DNS blocklists, Add blocklist.

## למי זה מתאים

- למי שמקפיד על הפרטיות שלו.
- למי שמעדיף לצמצם פרסומות.
- למי שרוצה למנוע דליפת מידע מיותרת.
- לשרתים ולבתים חכמים.

## הבהרות

- הרשימה אינה הרמטית, והזיהוי עשוי להתעכב עד 24 שעות.
- אם הרשימה אינה מתעדכנת אוטומטית אצלכם ב-AdGuard או ב-Pi-hole, יש להגדיר זאת בעצמכם. האחריות לכך היא של המשתמש.

## משוב

בכל בעיה או שאלה, מוזמנים לפתוח Issue בריפו או להשאיר תגובה.
